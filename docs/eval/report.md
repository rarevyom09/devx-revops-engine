### New observations

- **Over-correction on foreign currency (H01).** With "never convert, leave null and ask", the model returned no records at all and put the USD figure in `excluded_amounts` (a field meant for INR). Caught (`no_records`, low confidence), so not dangerous, but the reviewer gets nothing to edit. Proposed fix: prompt "still create the record with amount null"; validator: treat a foreign figure in `excluded_amounts` as not an exclusion.
- **E08 is a stable model failure** (2 of 2 runs). The validator catches it every time; a stronger fix would be to have code fill a default `rep_label_conflict` text when the label/terms conflict is detected, rather than only flagging.
- **Over-asking (H05).** The model wrote "assumed 2027 (next occurrence)" for "28 Feb" / "1 Mar" and asked two close-date questions, though the prompt settles year rollover. Harmless (medium confidence) but adds reviewer work.
- Held-out silent errors: 0 of 6. That is a small sample: one silent case would make it 17%.
